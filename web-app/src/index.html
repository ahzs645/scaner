A little help getting started
Quit Epson ScanSmart, FastFoto, Image Capture and Epson Scanner Monitor. Connect the scanner with USB and choose Connect scanner.
Load ordinary paper, choose color and sides, then scan. A sheet limit of 1 requests one physical sheet; 0 requests the loaded batch. Stop preserves completed pages, but the feeder may prefeed.
Click a thumbnail to inspect a page. Arrow keys move between pages; rotation edits are saved and exported as PNG. Auto-crop, automatic upright text and undo are in the Edit tab; each can be applied to one page or the whole scan. The export selector chooses edited pages or original JPEGs, with a settings manifest.
Saved jobs belong to this browser and address. Storage can be cleared or evicted, so export files you want to keep.
PDF, text extraction/searchable OCR, blank-page removal, photo restoration and maintenance controls are not implemented yet.
Supported scanners: Epson FF-680W. Interface inspired by Storytold's PhotoCraft and PdfCraft. This is an independent scanner app.

Create a measured scanner profile
Scan a physical reflective color reference target using consistent color capture, preferably at JPEG quality 100. Use the measured reference file supplied for that target. A home-printed chart does not provide known reference colors.
Use a regular rectangular grid and verify row-major patch order. For uneven IT8 layouts, select a regular color-patch block; omit separate grayscale strips. At least 24 usable patches are required. Clipped, uneven and insufficiently varied samples are rejected.
