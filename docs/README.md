# Development and validation notes

These dated notes preserve the driver investigations and hardware experiments.
The main README describes the current app; older notes can describe intermediate
implementations or features that were completed later.

Raw device captures, REA output, and screenshots containing scanned documents
are retained in the local workspace and deliberately excluded from this public
repository. Links to those artifacts in historical notes refer to local evidence,
not publicly hosted downloads. Synthetic test images and profiles are included.

Start with [modular drivers](modular-driver-processing.md),
[browser processing](browser-processing-research.md),
[network architecture](network-driver-design.md), and
[color pipeline](color-pipeline.md). Upstream research commits are recorded in
[`references/sources.json`](../references/sources.json).
